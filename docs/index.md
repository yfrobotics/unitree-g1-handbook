# 宇树 G1 使用手册

面向研究人员和开发者的宇树 G1 人形机器人实用指南。

初次使用 G1 时，你可能既感到兴奋，也会遇到令人头疼的问题。本手册是在探索机器人的过程中编写的，重点介绍 G1 EDU 版本，面向使用 G1 开展研究和开发的读者。

初次使用 G1？请先阅读[开箱指南](getting-started/unboxing.md)，完成机器人开机，再按照[网络连接指南](networking/connect-to-robot.md)建立连接。

## 目录

- [入门指南](getting-started/unboxing.md)：开箱、首次开机、遥控器基本操作及安全注意事项。
- [网络连接](networking/connect-to-robot.md)：通过以太网或 Wi-Fi 连接机器人，并配置互联网访问。
- [开发指南](development/sdk-setup.md)：SDK 配置、灵巧手 SDK、ROS2 集成及仿真环境。
- [硬件](hardware/specs.md)：规格、组件、传感器及感知能力。
- [故障排查](troubleshooting.md)：实际使用中的常见问题、错误代码及解决方法。

## 关于本手册

本手册由社区编写，属于非官方资料，与宇树科技无关联，也未获得其背书。内容基于 G1 EDU 的实际使用经验，旨在补充官方文档中未充分覆盖的内容。

发现错误或希望补充内容？欢迎在 [GitHub](https://github.com/yfrobotics/unitree-g1-handbook) 上参与贡献。
