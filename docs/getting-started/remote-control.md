# 遥控器使用

本页介绍遥控器准备、绑定和基础操作。先完成[开箱检查](unboxing.md)，在运动前核对与机身配置、固件相匹配的按键表。

## 开机与充电

本页所参考的官方手持遥控器使用“短按电源键一次，再长按超过 2 秒”的方式开关机。充电时关闭遥控器，通过 USB Type-C 接口连接符合说明要求的充电器。[官方遥控器说明，第 4—5 页](https://marketing.unitree.com/article/en/G1/Remote_Control.html)

装好可拆摇杆后检查回中情况，确认没有包装或手机支架压住按键。开机和进入模式时让摇杆保持中位，不要同时推杆和尝试不熟悉的组合键。

## 首次绑定

官方流程通过 Unitree Explore App 的遥控器设置启用遥控功能并填写对应遥控器编号。绑定后，所示型号右侧 `DL` 指示灯亮起，表示数传连接建立。[官方绑定说明，第 6 页](https://marketing.unitree.com/article/en/G1/Remote_Control.html)

1. 从[宇树官方下载页](https://www.unitree.com/app/g1/)安装适用于设备地区的 Unitree Explore。
2. 根据 App 的引导添加当前机器人，核对序列号，避免绑定到实验室另一台设备。
3. 使用遥控器实际编号完成绑定；不要照抄说明图中的示例编号。
4. 结合遥控器指示灯和 App 状态确认连接，再进行模式操作。

App 的菜单文字可能随版本变化。手机连上蓝牙或 Wi-Fi，只说明其中一条连接建立，仍应确认机器人与手持遥控器之间的链路。

## 基础摇杆操作

以下是所参考遥控说明中的基本方向映射，只有在匹配的运动模式下才使用：

| 操作 | 基本含义 |
| --- | --- |
| 左摇杆向前／向后 | 前进／后退 |
| 右摇杆向左／向右 | 左转／右转 |
| 松开摇杆回中 | 回到中位输入，具体停止或踏步行为由模式决定 |

方向图见[官方基础操作说明，第 6 页](https://marketing.unitree.com/article/en/G1/Remote_Control.html)。初次测试每次只轻推一个方向，短距离移动后回中观察，再测试转向。机器人朝向应便于操作者理解，避免面对机器人时把左右方向混淆。

## 模式与按键版本

先分清零力矩、阻尼、准备、运动以及调试模式，再记按键。阻尼和准备状态不等同于可自主平衡的行走状态；同样的摇杆输入在不同模式下也可能表现不同。

官方存在不同版本的按键资料。可从[遥控器完整说明](https://marketing.unitree.com/article/en/G1/Remote_Control.html)和[官方中文快捷表](https://oss-global-cdn.unitree.com/static/5014b2b84df94951b1e2197081e02822.pdf)核对，但只有与设备匹配的表才能用于实际操作。快捷表还区分短按、长按和双击，并注明部分操作仅适用三腰配置。

本手册建议把实际验证过的内容记在遥控器旁：

| 必须确认的操作 | 记录内容 |
| --- | --- |
| 当前姿态进入运动模式 | 起始支撑、组合键、等待状态 |
| 正常结束行走或预设动作 | 所在模式、按键方式、预期反馈 |
| 异常情况下的处置 | 当前模式可用的停止方式及支撑要求 |
| 进入开发模式 | 适用 SDK、控制权交接、退出方式 |
| 正常关机 | 落座或悬挂流程、状态要求、电源操作 |

不要把“某个按键能中断舞蹈”当成所有模式下通用的急停能力。底层开发时遥控器是否有效，需结合[安全指南](safety.md)和当前控制程序验证。

## 第一次操作练习

在可靠支撑和现场指导下完成启动，确认无告警后再按说明进入允许运动的状态。保持低速，依次练习短距离前进、回中、后退和小角度转向。每次都先观察响应，再进行下一项。

如果机器人持续偏移，先检查摇杆回中、模式和地面情况。摇杆校准只能在不会产生实机运动的条件下按官方校准流程进行，不能用快速切换模式来掩盖偏移问题。

## 无响应时怎么查

先确认遥控器电量和 `DL` 链路，再检查是否绑定正确设备、机器人是否完成初始化、当前模式是否接受遥控。若 SDK 正在运行，核对是否已经接管控制。仍异常时保存指示灯、App 告警和固件信息，见[故障排查](../troubleshooting.md)。
