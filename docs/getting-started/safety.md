# 安全指南

G1 的运动、失去平衡和关节夹持都可能造成人身伤害。首次操作前，应由设备负责人带领熟悉支撑设备、当前固件的控制模式和停止流程。本页整理日常实验要点，具体设备操作以匹配版本的官方说明为准。

## 场地与支撑

官方说明要求机器人保持在操作者视线内，并与障碍物、人群、水域等保持至少 2 米距离；同时要求平整、开阔的环境，避免湿滑、积水和粉尘场地。[官方环境要求，第 11 页](https://marketing.unitree.com/article/en/G1/User_Manual.html)

本手册建议根据计划动作、线缆长度和可能倒地范围进一步扩大隔离区域。初次实验由一人专门操作、一人观察；围观人员不进入测试范围。网线和电源线沿场地边缘布置，避免绊倒或被脚部卷入。

保护架和吊带应使用交付方案规定的受力点、长度和锁止方式。它们的安装错误也会产生风险，不应把普通挂钩、桌椅或未经确认的支架当作等效替代品。

## 开机前检查

- 电池、连接器和锁扣完好，机器人与遥控器电量满足本次操作要求。
- 关节区域无异物，脚底、传感器窗口和散热口无明显污染或遮挡。
- 起始姿态、支撑状态和当前固件对应的启动流程已核对。
- 操作者知道谁在发送命令，以及如何结束当前控制模式。
- 实验日志和停止条件已准备好，例如异常振动、温度告警、数据中断或人员进入场地。

上述列表是本手册建议的实验前检查表；详细的原厂检查项目见[开箱页](unboxing.md)引用的官方说明。

## 区分停止、阻尼与断电

| 状态或操作 | 需要理解的行为 |
| --- | --- |
| 摇杆回中或停止行走请求 | 不代表所有关节断电，也不保证立即停止所有预设动作 |
| 阻尼模式 | 与主动平衡站立不同，可能失去承重能力 |
| 零力矩或断电 | 无法依赖电机维持站姿，需要预先安排可靠支撑 |
| 关闭电脑程序 | 仅表示该进程退出，不等同于设备已安全停止 |

模式定义见[官方遥控器说明，第 7 页](https://doc-cdn.unitree.com/static/2025/6/6/96cfec69b8c541cfb4832468b7b6be19_2481x3508.png)。开始运动前，应在可靠支撑、受过培训的条件下确认当前模式的停止流程。不要在机器人已失稳时靠近抓接，也不要把临时拔电池作为常规停止方法。

## 开发时的控制权

官方说明提醒：高层开发时，遥控器和 API 命令可能同时生效；底层开发时，遥控命令可能失效。因此不能假设遥控器在任何 SDK 模式下都能接管机器人。[官方安全说明，第 3 页](https://marketing.unitree.com/article/en/G1/User_Manual.html)

本手册建议每次只保留一个经过确认的运动命令来源。底层控制前确认官方运控服务的交接流程，验证通信超时、命令限幅和程序退出后的设备行为；先在[仿真](../development/simulation.md)验证，再进行受支撑的实机测试。

持续订阅状态不需要为了“确保连接”而关闭原有运控服务。只有进入特定控制流程时，才按相应接口说明进行模式切换。

## 电池与充电

使用匹配电池的官方充电器，保持接口干燥、无金属异物。电池有鼓包、漏液、明显损伤、异味或异常发热时停止使用并联系设备负责人。

电池说明提供了充电保护指示：温度、电压、电流或短路异常会触发不同灯号。保护状态应先查明原因，不要反复插拔尝试绕过保护。[官方电池与充电器说明，第 6 页](https://marketing.unitree.com/article/en/G1/Battery_Charger.html)

充电地点应通风、远离可燃物，并遵守实验室的锂电池管理要求。充电温度、存放电量和维护周期按实际电池型号的说明执行。

## 发生异常后

先按已确认的停止流程处置，并让人员远离运动范围。机器人稳定后，记录当时模式、告警、最后命令、视频和软件版本。对碰撞后的结构松动、编码器异常或电池损伤，应先进行设备检查，再决定是否恢复通电。

检查和清洁时让设备处于说明书规定的稳定、关闭状态；不要带电拆装手部连接器或在未支撑的机身上拆卸关节。软件和网络问题可从[故障排查](../troubleshooting.md)继续定位。
