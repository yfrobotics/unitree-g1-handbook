# G1 开箱

第一次开箱的目标是完成设备检查、准备可靠支撑，并确认机器人能按交付版本的流程启动和关闭。请先阅读[安全指南](safety.md)，再进行搬运和通电。

## 准备场地和人员

本手册建议至少两名成年人协作，一人负责主要操作，一人观察支撑、线缆和周围空间。准备平整、干燥、无障碍的场地，以及交付资料指定的保护架或其他支撑设备。

将包装箱按标识正面朝上放稳，打开后分别取出机器人及附件。宇树说明书要求检查部件状态、电量和保护架，使用带脚轮的支架时检查锁止状态。[官方使用说明，第 11—12 页](https://marketing.unitree.com/article/en/G1/User_Manual.html)

不要通过拉拽手指、外露线缆、传感器或外壳边缘搬运机器人。搬运和悬挂位置应按对应设备图示确认；无法确认受力位置时，先向交付人员核实。

## 清点与检查

按实际订单逐项核对，不要把下表理解为所有版本的标准装箱清单：

| 项目 | 检查内容 |
| --- | --- |
| 机器人本体 | 外壳、关节、脚底、传感器窗口有无运输损伤 |
| 电池与充电器 | 型号、外观、接口和锁扣是否匹配、完好 |
| 遥控器及附件 | 摇杆、充电线、开关和按键是否完好 |
| 保护架、吊带或紧固件 | 数量、额定承载、安装方式及锁止状态 |
| 灵巧手或其他末端 | 型号、左右手、线缆、固定结构 |
| 交付资料 | 序列号、配置单、使用说明、开发账户和售后联系人 |

拍照记录装箱状态和异常部位，并保留包装。发现变形、破损、电池鼓包或接口松脱时，先处理交付问题，不要尝试用开机动作验证损伤程度。

## 建立设备记录

在首次实验前填写一份设备记录，后续软件问题会更容易复现：

```text
机器人型号与序列号：
机身自由度／腰部配置：
左右末端型号：
开发计算单元型号：
系统与固件版本：
遥控器编号与按键表版本：
开发接口 IP 与账户来源：
首次检查日期与负责人：
```

不同配置对模型和 SDK 有直接影响，详见[规格与组件](../hardware/specs.md)。

## 首次通电

1. 根据该版本说明书选择坐姿或悬挂启动方式，完成支撑和姿态准备。
2. 确认电池方向正确并完全锁扣到位；遇到阻力时不要强行压入。
3. 检查遥控器电量、摇杆回中和连接状态，提前明确正常停止与异常处置方式。
4. 按交付说明执行电源操作，等待初始化完成，再核对 App 状态或告警。
5. 仅在支撑、姿态和模式均符合说明书要求时，继续进入后续运动模式。

坐姿准备和电池安装细节见[官方说明第 12 页](https://doc-cdn.unitree.com/static/2026/8/12/81d76fa75a1742958367e27c7b1fa353_2481x3509.png)。开机姿态和模式切换具有版本差异，本页的顺序用于检查准备工作，具体按键和支撑动作需逐项对照随机器说明。

## 第一次验收与关机

先确认状态显示和遥控连接，再在受控场地进行短距离、低速的基础测试。第一次验收不需要舞蹈、跑步、跳跃或复杂地形动作。记录告警和异常声音；如果有异常，停止测试并转到[故障排查](../troubleshooting.md)。

关机前先按说明书让机器人落座或由保护架承重，再进入规定状态并执行电源关闭。站立时直接断电可能导致倒地；关节附近仍需防止夹伤。[官方关机说明，第 22 页](https://marketing.unitree.com/article/en/G1/User_Manual.html)

完成后确认设备稳定、线缆收妥，再按电池说明处理充电和存放。下一步阅读[遥控器使用](remote-control.md)和[连接机器人](../networking/connect-to-robot.md)。
