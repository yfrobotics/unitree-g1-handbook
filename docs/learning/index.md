## 建议阅读路径

第一次学习实验先完成 CPU 行为克隆；准备实机操作数据时走采集与转换 → ACT 基线 → VLA。行走学习从强化学习页开始；参考动作跟踪从动作数据 → SONIC 开始，随后再考虑与任务策略结合。
