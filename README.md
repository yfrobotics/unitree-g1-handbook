# Unitree G1 Handbook

Everything about Unitree G1 for beginners.

It could be both exciting and very frustrating to firstly use G1. I write this handbook while myself is exploring the robot. This handbook will focus on the G1 EDU version, and in particular for research and development purposes.

- Official development guide (online): https://support.unitree.com/home/en/G1_developer
- Official SDK: https://github.com/unitreerobotics/unitree_sdk2
